How to use Better Reads

Before reading: Find a book, then create a preview prompt. Copy it into ChatGPT and paste the response back into the book's Preview report.
After reading: Generate a review prompt for a fuller summary, key points and practical lessons. Save the AI response in the Review report.
Your voice matters: Use the Reading Journal to record your own conclusions, disagreements and favourite ideas. Your notes are kept separately from AI-generated content.

This first version does not require an API key or subscription. Your library is saved in this browser on this device. Use Export backup regularly to keep a copy.

Find a Book

Enter a title and author, or search the Google Books catalogue.

Catalogue search uses Open Library's public catalogue for bibliographic information and cover images where available. It does not provide the complete book text.

How AI summaries work

Better Reads prepares a tailored prompt. You copy it into ChatGPT (or another AI assistant), then paste the answer into the matching report field. The app does not pretend to have access to a complete book when only public descriptions are available.

For accurate chapter-by-chapter notes, the AI should have reliable chapter information. If it cannot verify the chapter structure, it must say so rather than invent chapter summaries.
